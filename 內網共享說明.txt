內網共享說明 (俾同事用呢個工具)
=====================================

原理
----
你部機做「伺服器」, 同事喺同一個公司網絡, 用瀏覽器開你部機嘅 IP 就用到。
資料唔會出公司, 同事都唔使裝 Python。

=====================================
第一步: 你部機啟動 (同平時一樣)
=====================================
雙擊 start.bat。
今次啟動後, 黑色視窗會顯示兩條網址, 例如:

  你自己開:      http://127.0.0.1:5150
  同事內網開:    http://192.168.1.50:5150

抄低「同事內網開」嗰條 (你部機實際 IP 會唔同)。

=====================================
第二步: 話俾同事
=====================================
將「同事內網開」嗰條網址 send 俾同事 (例如貼上公司群組)。
同事喺自己部機開瀏覽器, 打呢條網址就入到, 一樣可以揀原因、分析、睇明細。

=====================================
注意事項
=====================================
1. 你部機要開住 + start.bat 要 run 住
   - 你部機關機 / sleep / 熄咗個黑色視窗, 同事就入唔到
   - 適合返工時間開住

2. 同事要同你喺同一個公司網絡 (同一 WiFi / 同一區域網)
   - 喺屋企 / 出面就入唔到 (嗰啲要方法 B 雲端)

3. 第一次同事入唔到? 多數係防火牆擋咗
   Windows 防火牆設定:
   - 搜尋 "Windows Defender Firewall"
   - 左邊撳 "Allow an app through firewall"
   - 撳 "Change settings" -> "Allow another app"
   - 揀 python.exe (通常喺 C:\Users\pchan\AppData\Local\Programs\Python\...)
   - 剔 "Private" (私人網絡)
   - 確定
   或者第一次 run 時 Windows 會彈窗問, 揀 "允許存取" 就得

4. 你部機 IP 可能會變
   - 如果重開機後 IP 變咗, 同事條網址都要更新
   - 想固定, 可以叫 IT 幫你部機設 "靜態 IP" (唔急嘅話唔使)

5. 幾多人同時用都得
   - Flask 開發伺服器可以應付幾個同事同時睇
   - 如果成隊人 (10+) 一齊用先至可能要考慮方法 B

=====================================
安全提醒
=====================================
- 呢個工具冇登入功能, 任何知道網址 + 喺公司網絡嘅人都入到
- 你張 Google Sheet 已經係「知道連結可檢視」, 內容唔算機密先啱用呢個方式
- 如果日後 Sheet 加入客人個人資料, 就唔應該咁樣開放, 要加登入或改用其他方式
